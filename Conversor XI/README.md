# Conversor XI

## Objetivo

Desenvolver uma aplicação em Python capaz de converter valores entre **números inteiros e números romanos**, através de uma interface gráfica criada com **PyQt5**.

---

## Descrição

O **Conversor XI** é uma aplicação simples desenvolvida em Python para realizar conversões entre a representação decimal e a representação em números romanos.

A aplicação permite:

* converter um número para a sua representação em números romanos;
* converter um número romano para o respetivo número;
* utilizar uma interface gráfica para introduzir e visualizar os valores;

A interface visual foi desenvolvida com base num mockup de iPhone.

---

## Estrutura

**Conversor XI/**

* **mockup_iphone.py:** ficheiro utilizado como referência para a interface visual da aplicação
* **code.py:** contém a lógica responsável pelas conversões entre números e números romanos
* **main.py:** instancia a aplicação e inicia a sua execução

> **Nota:** o ficheiro `main.py` é o ficheiro utilizado para executar a aplicação.
