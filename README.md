# Projetos PyQt5 Base

## Objetivo

O repositório reúne projetos desenvolvidos em Python com recurso ao **PyQt5**, sobretudo aplicações de menor dimensão, projetos pessoais e experiências que não estão diretamente relacionadas com a área de **Machine Learning**.

O objetivo é manter num único espaço projetos que permitam explorar diferentes aspetos do desenvolvimento em Python, desde interfaces gráficas e interação com o utilizador até lógica de aplicações e organização de código.

---

## Descrição

Este repositório funciona como uma coleção de projetos independentes desenvolvidos ao longo do meu percurso de aprendizagem e experimentação com Python e PyQt5.

Os projetos aqui presentes não têm necessariamente uma relação direta entre si nem seguem uma única linha temática. Em comum, têm o objetivo de servir como espaço para:

* desenvolver aplicações completas em Python;
* explorar o desenvolvimento de interfaces gráficas;
* trabalhar lógica e interação com o utilizador;
* experimentar diferentes funcionalidades do PyQt5;
* aplicar conceitos de programação fora do contexto de Machine Learning;
* testar ideias e transformar pequenos projetos em aplicações funcionais.

Apesar de serem projetos de natureza mais geral, procuro manter uma preocupação com a organização do código, clareza da lógica e experiência de utilização.
